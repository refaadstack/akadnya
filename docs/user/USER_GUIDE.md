## 🌐 Mengatur Subdomain

### Apa itu Subdomain?
Subdomain adalah alamat unik untuk undangan Anda.  
Contoh: `siti-budi-2024.akadnya.com`

### Cara Mengubah Subdomain

1. Buka **Dashboard** → **Settings**
2. Di bagian **Subdomain**, ketik subdomain baru
3. Klik **Simpan Subdomain**

### Aturan Subdomain
- ✅ Minimal 3 karakter, maksimal 50 karakter
- ✅ Hanya huruf kecil (a-z), angka (0-9), dan tanda hubung (-)
- ❌ Tidak boleh spasi atau karakter khusus
- ✅ Harus unik (belum dipakai user lain)

### Contoh Subdomain yang Baik
- `siti-dan-budi`
- `pernikahan-kami-2024`
- `wedding-jakarta`
- `akad-nikah-siti-budi`

### Generate Random
Jika bingung memilih, klik tombol **Generate Random** untuk mendapatkan subdomain acak.

## 📢 Mempublikasikan Undangan

### Cara Publikasi

1. Buka **Dashboard** → **Settings**
2. Pastikan konten sudah lengkap:
   - Nama mempelai wanita & pria ✓
   - Tanggal & waktu akad ✓
   - Tempat akad ✓
3. Klik tombol **Publikasikan**
4. Undangan sekarang bisa diakses publik!

### Status Publikasi
- **Draft** - Undangan belum bisa diakses publik
- **Published** - Undangan bisa diakses via URL

### Membagikan Undangan
Setelah dipublikasikan:
1. Copy URL undangan (klik tombol **Salin**)
2. Bagikan ke tamu via WhatsApp, email, atau media sosial
3. Tamu bisa langsung buka tanpa login

### Unpublish
Jika perlu unpublish (misalnya ada perubahan):
1. Klik tombol **Unpublish**
2. Undangan tidak bisa diakses sementara
3. Edit konten yang perlu diubah
4. Publikasikan kembali

## 🌟 Custom Domain (Premium)

### Apa itu Custom Domain?
Gunakan domain sendiri untuk undangan.  
Contoh: `undangan.example.com` atau `wedding.mydomain.id`

### Cara Setup Custom Domain

#### 1. Beli Domain
Beli domain dari provider seperti:
- Niagahoster
- Dewaweb
- Namecheap
- GoDaddy

#### 2. Setup DNS
1. Login ke DNS Management di provider domain
2. Buat **CNAME record**:
   - **Type**: CNAME
   - **Name**: undangan (atau subdomain lain)
   - **Value**: akadnya.com
3. Simpan perubahan

#### 3. Tunggu Propagasi
- DNS propagasi memakan waktu 5-30 menit
- Kadang bisa sampai 24 jam
- Cek status di [whatsmydns.net](https://www.whatsmydns.net/)

#### 4. Masukkan di Akadnya
1. Buka **Dashboard** → **Settings**
2. Di bagian **Custom Domain**, masukkan domain Anda
3. Klik **Simpan Custom Domain**
4. Verifikasi dengan membuka domain di browser

### Troubleshooting Custom Domain

**❓ Domain tidak bisa diakses?**  
→ Tunggu propagasi DNS (bisa sampai 24 jam)

**❓ Error "Domain sudah digunakan"?**  
→ Domain sudah dipakai user lain, gunakan subdomain berbeda

**❓ Tidak punya domain?**  
→ Gunakan subdomain gratis Akadnya saja, sudah cukup!

## ❓ FAQ (Pertanyaan Umum)

### Umum

**Q: Apakah undangan bisa diakses tanpa internet?**  
A: Tidak, undangan digital memerlukan koneksi internet.

**Q: Berapa lama undangan aktif?**  
A: Sesuai paket yang dibeli (1 bulan, 3 bulan, atau selamanya).

**Q: Bisa ganti template setelah beli?**  
A: Tidak, template tidak bisa diganti. Pilih dengan hati-hati.

**Q: Apakah ada batasan jumlah tamu?**  
A: Tidak ada batasan, unlimited guests.

### Subdomain

**Q: Kenapa subdomain auto jadi nama saya?**  
A: Sistem otomatis generate dari nama mempelai/user untuk kemudahan. Tapi bisa diubah kapan saja.

**Q: Bisa ganti subdomain setelah publikasi?**  
A: Bisa, tapi URL lama tidak akan berfungsi lagi.

**Q: Subdomain yang sudah dipakai bisa diambil lagi?**  
A: Tidak, subdomain bersifat unik dan tidak bisa dipakai ulang.

### Konten

**Q: Ukuran maksimal foto?**  
A: Cover & mempelai: 5MB, Galeri: 5MB per foto, QRIS: 2MB.

**Q: Format foto yang didukung?**  
A: JPG, PNG, WebP.

**Q: Ukuran maksimal musik?**  
A: 10MB per file.

**Q: Format musik yang didukung?**  
A: MP3, WAV.

### Publikasi

**Q: Apakah bisa unpublish setelah publikasi?**  
A: Bisa, klik tombol Unpublish di Settings.

**Q: Apakah tamu perlu login untuk melihat?**  
A: Tidak, tamu bisa langsung buka tanpa login.

**Q: Bagaimana cara tracking views?**  
A: Lihat di Dashboard, ada counter views.
