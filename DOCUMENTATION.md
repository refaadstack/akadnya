### Untuk Membuat Template Baru:
1. Baca [Template Creation Guide](docs/templates/TEMPLATE_CREATION_GUIDE.md) - **START HERE!**
2. Lihat [Betawi Heritage Preset](docs/templates/BETAWI_HERITAGE_PRESET.md) sebagai contoh
3. Gunakan [Styling Patterns](docs/templates/STYLING_PATTERNS.md) untuk konsistensi
4. Buat folder template dengan struktur yang benar
5. Buat `template.json` dan section files
6. ZIP folder dan upload via admin panel

### Untuk Develop Template Javanese:
1. Copy pattern dari Betawi Heritage preset
2. Ganti warna dan ornamen sesuai tema Javanese
3. Ikuti styling patterns yang sama
